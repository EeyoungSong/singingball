# 삼색 고양이 에셋

승인된 `reference.png`의 주황·차콜·크림색 무늬를 기준으로 만든 투명 PNG 12장입니다.

| 폴더 | 파일 | 캔버스 | 용도 |
| --- | --- | --- | --- |
| hit | hit_01.png ~ hit_09.png | 1254 × 1254 | 싱잉볼 연주 |
| walk | walk-a.png, walk-b.png | 887 × 1774 | 두 자세를 번갈아 재생하는 걷기 |
| walk | stand.png | 887 × 1774 | 서 있기 |

`preview.html`을 브라우저에서 열면 전체 프레임, 연주·걷기 재생, 배경색 변경을 확인할 수 있습니다. 인터넷 연결이나 설치가 필요하지 않습니다.

연주 순서는 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09입니다. 기존 에셋과 같은 복귀 구성이므로 07은 03, 08은 02, 09는 01의 복사본입니다. 연주 프레임 간격은 85ms, 걷기는 180ms를 미리보기 기본값으로 사용했습니다.

걷기·서 있기 이미지의 상단 투명 여백은 기존 레이아웃에 맞춰 유지했습니다. 연주 이미지는 생성 과정에서 기존 흰 고양이보다 크게 배치되어, 앱에서는 CSS로 크기와 위치를 보정해 기존 싱잉볼 오버레이에 맞췄습니다. 프레임별 질감에는 미세한 차이가 있습니다. 앱의 `꾸미기 → 고양이`에서 흰 고양이와 삼색 고양이를 선택할 수 있으며 선택은 기기에 저장됩니다. 초기 선택은 기존 흰 고양이입니다.

내장 `image_gen`으로 생성했으며, 최종 프롬프트는 `prompts.json`에 기록했습니다. 생성된 알파 채널을 그대로 보존했습니다. `validation.json`에는 각 프레임의 크기, 알파 경계와 픽셀 검사 결과가 있습니다. `reference.png`는 흰 배경의 승인 시안이며 애니메이션 프레임이 아닙니다.
